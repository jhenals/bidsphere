# BidSphere — Distributed Real-Time Auction Platform
Designed and implemented a distributed auction platform using Java/Spring Boot, Redis, Kafka, WebSockets, MySQL and Docker, implementing concurrency-safe bid processing, distributed locking, event-driven workflows, auction expiration, simulated payment processing and real-time client updates. Developed concurrent load tests to validate system consistency under high bid contention and implemented idempotent event processing for eventual-consistency scenarios.
